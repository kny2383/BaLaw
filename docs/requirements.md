## 서비스 정의

- **대상 사용자.** 법률 지식이 부족하고 변호사 선임이 어려운 일반인, 특히 소액 사기 피해자. (D1, D4)
- **해결하는 문제.** 고소장 필수 사실관계 누락, 법률 용어·양식의 진입장벽, 피해액보다 큰 선임 비용. (D1, D2, D4)
- **서비스 성격.** 법률 판단·자문이 아니라, 사용자가 입력한 사실을 표준 양식에 맞게 정리하는 **문서 작성 보조 서비스**. (D4)
- **MVP 범위.** 형법 제347조 사기죄. (D1, D4)
- **현재 지원 범위 (결정 0001).** 사기(사이버사기 포함)만 정식 지원. 모욕·명예훼손은 평가 후 재결정, 다음 확장은 개인 간 단순 횡령. 작성 화면의 나머지 죄목은 "준비 중"으로 표시.

## 문서 간 불일치

| 항목 | 내용 | 정리 방향 |
|---|---|---|
| 단계 순서 | D1~D3은 인적정보 → 사전 확인, D4는 사전 확인 → 인적정보 | D4 순서를 기준으로 화면 확인 |
| 죄목 결정 주체 | D1~D3은 "AI가 죄목 추정", D4는 "판례를 보고 사용자가 선택" | 현재 코드는 D4대로 사용자가 선택. D4 기준으로 확정 |
| 관할 경찰서 기준 | D4는 고소인 주소, D2는 고소인·피고소인 주소 | **확정:** D4대로 고소인 주소 기준. 현재 코드(피고소인 우선)를 3단계에서 수정 |
| 배포처 | D1~D3은 Render, D4는 EC2 | D4 기준 |
| 암호화 방식 | D1·D3은 AES-256 | **확정:** 실제 방식인 Fernet으로 표기 |
| 파일 저장 | D1·D3은 생성 DOCX를 S3에 임시 저장 | 현재 구조 기준으로 정리 |
| 임베딩 모델 | D1은 text-embedding-ada-002 | 실제 모델로 수정 |
| 삭제 정책 | D3에만 7일 세션·90일 로그 | **확정:** 7일 미활동 삭제는 구현, 90일 로그는 범위 제외 |
