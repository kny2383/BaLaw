# 프롬프트 수정 뒤 검증·재작성의 추가 효과 (prompt-verify-dev10)

작성 프롬프트를 고친 뒤의 초안(`compose-prompt-dev10`)에 검증·재작성을 적용했다. 대화, 추출, 작성은 다시 하지 않았다.

## 실행 조건

| 항목 | 값 |
|---|---|
| 원래 초안 | compose-prompt-dev10 (main 261d662의 작성 프롬프트, 개발 10건) |
| 검증·재작성 | `eval/verify_drafts.py`, 브랜치 `feat/verify-rewrite`, gpt-5-mini-2025-08-07, 재작성 상한 1 |
| 판정 | `eval/rejudge.py`, openai/gpt-5-2025-08-07, 판정 기준 2판 |
| date_utc | 2026-11-26 |
| 실행 횟수 | 1 |

## 읽은 것 (사람 1명, 1회)

- **검증이 찾은 11개 중 4개는 고칠 필요가 없는 표현이었다.** insult-01의 3개("32명인 점에 비추어 다수에게 노출", "고소하게 되었습니다", 처벌 요구 문장)와 fraud-used-goods-03의 1개("약속을 신뢰하여")다. 판정이 0개로 본 초안(insult-01)에서 3개를 지적했다.
- **그래도 사용자가 말한 사실이 지워진 경우는 없었다.** 재작성은 지적된 문장에서 근거 없는 부분만 뺐고, 처벌 요구 문장은 검증이 지적했는데도 남겼다 (재작성 규칙). insult-01에서 지워진 두 문장의 내용은 다른 문장에 남아 있다.
- 남은 7개는 "판매 게시물을 보고", "전화를 걸어 은행 직원이라고 소개", "2026. 5.", "돌려받지 못하고 있다", "재산상 손해를 입었다"다. 검증이 찾지 못했다.

## 한계

- **판정 흔들림이 효과의 일부다.** 초안이 한 글자도 바뀌지 않은 3건의 판정이 2 → 0, 2 → 2, 0 → 0이었다. pii-02는 표현 1개를 고쳤는데 4 → 0이 됐다. 21 → 7의 감소 14개 중 적어도 5개 안팎은 초안 변화가 아니라 판정 차이다. 같은 초안을 여러 번 판정해 흔들림 폭을 재기 전에는 "추가로 줄어든다"까지만 말할 수 있다.
- 검증 기준과 판정 기준이 같은 구분을 쓴다.
- 10건, 1회 실행이다. 최종 숫자는 보류 세트로 다시 잰다.
- 사용자가 말한 사실이 초안에 남아 있는 비율은 지표로 재지 않았다 (위는 사람이 읽은 것).
