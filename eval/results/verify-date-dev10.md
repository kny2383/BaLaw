# 초안 검증이 "다른 일에 붙은 날짜"를 잡아 묻지 않고 고치게 함 (개발 세트 10건)

2026-11-28. 서비스 모델 `gpt-6.1-terra`, 판정 `gpt-6.1-sol`, 판정 기준 3판. 보류 세트는 열지 않았다.

## 문제

사용자가 한 가지 일의 날짜만 말했는데 초안이 그 날짜를 다른 일에도 붙이는 경우가 남아 있다 (`wobble-dev10.md`의 `pii-02`: "2024년 2월 계약"이라고만 했는데 "2024. 2. … 보증금을 이체"). 질문 단계는 날짜가 어느 일의 것인지 묻지 않고, 초안 검증도 이 종류를 잡지 못했다.

## 바꾼 것

1. 검증 지시문: 날짜마다 사용자가 그때 무슨 일이 있었다고 했는지 대화에서 확인하고, 초안이 그 날짜를 다른 일에 붙였으면 그 구절을 짚는다. 검증 결과에 `date_moved`(그 일은 사용자가 말했고 날짜만 다른 일의 것) 표시를 더했다.
2. `date_moved`인 표현은 사용자에게 묻지 않고 바로 고친다. "이 일이 사실인가요?"라고 물으면 사용자는 그 일이 있었으니 맞다고 답하고, 맞다고 한 표현은 그대로 두므로 날짜가 남기 때문이다.
3. 재작성 지시문: `date_moved`인 표현은 그 일을 지우지 않고 날짜만 뗀다.

## 방법

날짜 문제가 있는 초안 10건(`date-before-drafts`: 작성 지시문의 날짜 규칙(#86)을 넣기 전의 초안)에 검증·재작성만 다시 돌렸다 (`verify_drafts.py`, 묻지 않고 고치는 설정). 같은 초안에 지금 검증(`vdate-before`)과 고친 검증(`vdate-final`)을 각각 적용해 판정했다. 각 1회.

## 결과

| | 지금 검증 | 고친 검증 |
|---|---|---|
| M1 지어낸 사실 (건) | 4 | 1 |
| M8 단정 표현 | 0 | 0 |
| 검증이 찾은 표현 | 3개 (날짜 0) | 7개 (날짜 4) |

판정이 지적한 4건은 모두 날짜가 다른 일에 붙은 종류다 (`fraud-jeonse-04`, `fraud-voice-phishing-03`, `pii-02`, `sparse-03`). 고친 검증은 그 가운데 3건을 잡아 고쳤고 `fraud-jeonse-04`를 놓쳤다.

`date_moved` 표시: 날짜 종류 4개는 모두 참, 날짜와 무관한 3개(누가 요구했는지, 누가 가지고 있는지)는 모두 거짓이었다.

고친 초안 (사실은 남고 날짜만 떨어졌다):

| 사례 | 고치기 전 | 고친 뒤 |
|---|---|---|
| pii-02 | 2024. 2. … 계약을 체결하고, 보증금 1억 2천만 원을 … 이체하였습니다 | 2024. 2. … 계약을 체결하였습니다. 고소인은 보증금 1억 2천만 원을 … 이체하였습니다 |
| sparse-03 | 피고소인은 2026년 5월경 위 대화방에서 … 수익을 보장한다고 하였습니다 | 피고소인은 위 대화방에서 … 수익을 보장한다고 하였습니다 (이체 문장의 "2026년 5월경"은 남음) |

## 지시문을 고치며 본 것 (같은 초안, 각 1회)

| 시도 | 잡은 날짜 문제 (jeonse-04 / pii-02 / sparse-03) | 잘못 잡은 것 |
|---|---|---|
| 지금 검증 | 못 잡음 / 못 잡음 / 못 잡음 | - |
| 규칙 한 줄 | 잡음 / 못 잡음 / 잡음 | 사용자가 말한 날짜 2개 (sparse-03의 이체, vague-02) |
| + "한 문장에서 날짜 하나가 여러 일에 걸린 경우" | 잡음 / 잡음 / 잡음 | 없음 |
| + `date_moved` 표시 (최종) | 못 잡음 / 잡음 / 잡음 | 없음 |

## 한계

- 각 1회다. `fraud-jeonse-04`는 같은 규칙으로 두 번 잡히고 최종 실행에서 놓쳤다. 검증이 이 종류를 매번 잡지는 못한다.
- 이 초안들은 #86, #87 이전의 것이라 날짜 문제가 많다. 지금 서비스의 초안에는 이 종류가 드물어서(4회 실행에 1건) 전체 실행에서의 효과는 작게 나타날 것이다. 전체 실행으로는 재지 않았다.
- 사용자에게 묻고 멈추는 경로(기본 설정)는 테스트로만 확인했다: `date_moved` 표현은 물을 개수에 들지 않고, 나머지를 사용자가 모두 맞다고 답해도 고쳐진다.
- 날짜를 떼면 초안에서 그 일의 시점이 사라진다. 사용자가 실제로 같은 날 한 일이었다면 초안에서 직접 날짜를 넣어야 한다. 화면은 고친 표현을 따로 알려 주지 않는다.
